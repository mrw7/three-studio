# Scene examples

These are standalone scene scripts for the Three.js sandbox. They use the
globals provided by the preview (`THREE`, `scene`, `camera`, `renderer`,
`clock`, `controls`, `onFrame`, asset helpers).

- `scene-watch.js` — blue mechanical watch product showcase (the scene used in
  the documentation screenshots)
- `scene-city.js` — procedural hand-drawn night city

To use one, ask the AI to adopt it, paste it into a prompt as the scene code, or
seed it through the scene engine during development. The examples are provided
as reference material and are covered by the repository's no-license notice.
