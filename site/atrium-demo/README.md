# ATRIUM — spatial walkthrough

A procedural museum/gallery corridor with columns, skylights, framed art, a
central sculpture and a scroll/drag camera walkthrough.

## Run

```sh
python3 -m http.server 4173 --directory site
# open http://127.0.0.1:4173/atrium-demo/
```

## What it demonstrates

- Fully procedural architecture: no imported models or textures
- Warm gallery lighting, reflective floor, dust and a central chrome sculpture
- Camera path with wheel/drag/back/forward controls
- Auto tour, pause, reset and position HUD
- Responsive overlay for desktop and mobile

## Sales use

Use for real estate, cultural tourism, exhibitions, retail spaces and brand
environments. The same walkthrough can be adapted to a floor plan, a product
showroom or an architectural visualization.
