# Trademark policy

The names **Three Studio** and **Three Workbench**, and any project logo, are
project marks. The Apache-2.0 license covers code, not names or logos.

## Allowed

- Referring to the project by name in articles, talks, tutorials, comparisons
  and package metadata.
- Redistributing an unmodified release and saying it is "Three Studio".
- Using the name to describe a fork's origin, for example "a fork of Three
  Studio", as long as the fork is clearly distinguished.

## Not allowed without written permission

- Using the name or logo for a modified version in a way that suggests it is
  the official project.
- Using the name or logo in a product, hosted service or company name that
  implies endorsement or affiliation.
- Registering a domain, package name or social account that is confusingly
  similar to the project marks.

## Forks

If you distribute a modified version, rename it and replace the logo. You may
state that it is derived from Three Studio and link to the upstream project.

## Third-party names

Three Studio is not affiliated with the three.js project, DeepSeek, Anthropic,
Meta, or any other company or project mentioned in the documentation. Their
names and logos belong to their respective owners.
